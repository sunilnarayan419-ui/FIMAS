# Mathematical Framework

Document each model with: notation, units, assumptions, governing equations, boundary
conditions, feasibility constraints, numerical method, and validation tests.

Required candidate models:
- Dynamic graph state and edge reinforcement/decay.
- Conductance and flow conservation.
- Resource allocation constraints.
- Agent utility and exchange rules.
- Objective function and baseline formulations.

Do not insert equations until their variables, assumptions, and source rationale are clear.
