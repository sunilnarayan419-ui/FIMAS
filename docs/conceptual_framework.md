# Conceptual Framework

Candidate biological mechanisms:
1. Hyphal extension -> local exploration or new edge creation.
2. Edge reinforcement -> increased conductance or preference after useful flow.
3. Pathway decay -> reduced investment in underutilized edges.
4. Anastomosis -> reconnection between compatible paths.
5. Mycorrhizal exchange -> local resource exchange between agents.

Each mapping is a modeling hypothesis, not proof that engineered networks will exhibit the
same behavior as living systems. Record the mathematical rule and evidence supporting each
mapping.
