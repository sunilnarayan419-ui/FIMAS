# Evaluation Metrics

Candidate metrics include:
- Throughput: successfully delivered resource or traffic per unit time.
- Latency: clearly defined end-to-end or scheduling delay.
- Convergence: objective value against iteration count and wall-clock budget.
- Fairness: Jain's fairness index and/or Gini coefficient with a stated interpretation.
- Resilience: performance retained after a precisely specified failure event.
- Feasibility: constraint violations, unmet demand, and resource conservation error.

Define denominators, units, aggregation, and failure handling before measurement.
