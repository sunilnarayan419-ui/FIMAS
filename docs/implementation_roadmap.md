# Implementation Roadmap

## Phase I — Research specification
Verify literature, define research questions, formalize models, and establish evaluation plans.

## Phase II — Minimal scientific core
Implement graph state, allocation constraints, one baseline, and invariant tests.

## Phase III — Simulation and comparisons
Add scenarios, controlled failures, repeated trials, and statistical reporting.

## Phase IV — Service and visualization
Add API contracts, market event processing, and interactive visualization after the core model
is stable.

## Phase V — Reproducibility and release
Automate tests, document limitations, archive configuration and results, and prepare a release.
