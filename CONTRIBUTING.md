# Contributing

1. Open an issue describing the scientific or engineering problem.
2. For algorithm changes, explain the hypothesis, assumptions, and expected behavior.
3. Add or update tests, including scientific invariants where relevant.
4. Record configuration, random seed, and benchmark protocol for reported results.
5. Do not present unverified references or unmeasured performance as established evidence.
6. Keep generated datasets and large artifacts out of Git unless explicitly approved.
