# E01 — Topology Resilience

## Question
How does the candidate dynamic topology method compare with a static baseline after edge failures?

## Protocol requirements
- Define graph families and graph sizes.
- Define random versus targeted failure distributions.
- Specify whether exactly or approximately 40% of edges are removed.
- Define throughput before and after failure and the denominator for retained throughput.
- Compare methods on identical graph instances and seeds.
- Report distributions and uncertainty across independent trials.
